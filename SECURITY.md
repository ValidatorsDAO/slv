# Security policy

ELSOUL LABO B.V. is the responsible legal entity for SLV distribution and
security.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/ValidatorsDAO/slv/security/advisories/new)
to report an undisclosed SLV vulnerability. A GitHub account is required to use
the submission form.

Please include the affected SLV version, reproduction steps, and the security
impact. Do not include private keys, credentials, tokens, customer data, or
other sensitive information that is unnecessary to explain the issue. Do not
disclose an undisclosed vulnerability in public issues.

This reporting setting is enabled. Submission-form access, test-report delivery,
and notification routing have not yet been verified.

## Security fixes and supported updates

Security fixes are provided free through the latest public SLV version, without
Enterprise. There is no blanket promise to individually backport each fix to
older versions; applicable law and existing contracts remain preserved.

Where a latest-version upgrade would require extraordinary migration costs, such
as new hardware or a fundamental environment change, remediation is assessed
case by case. Normal updating, testing, and configuration effort is not
inherently extraordinary.
