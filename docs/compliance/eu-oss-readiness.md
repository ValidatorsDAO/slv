# Security, licensing, and release references

Use these documents to understand SLV's licensing, security updates, and release
verification:

- [License](../../LICENSE.txt): terms for SLV source and distributions.
- [Security policy](../../SECURITY.md): vulnerability reporting and security updates.
- [Credentials and 1Password](../credentials-and-1password.md): user authentication,
  credential storage, and validator identity handling.
- [Secure release delivery](../secure-delivery.md): installation, artifact
  verification, recovery, and the limits of build evidence.
- [Rebuilding releases](../rebuilding-releases.md): source and build inputs used
  to reproduce distributed artifacts.

For a particular version, use its [GitHub release](https://github.com/ValidatorsDAO/slv/releases)
and the accompanying manifest, SBOM, notices, source archives, and provenance.
Match the evidence to that version and source revision using the verification
procedure above. A successful source test or pull-request build does not by
itself verify a published release.

These materials describe the software and its release evidence; they are not a
CRA conformity assessment, certification, or CE declaration.
